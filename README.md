# Policies for use in the Cloud Custodian plugin

## Testing

```shell
opa test policies
```

## Bundling

Policies are built into a bundle to make distribution easier.

```shell
make build
```

## Writing policies

Policies are written in [Rego](https://www.openpolicyagent.org/docs/latest/policy-language/).

Use the standardized payload generated by the Cloud Custodian plugin as policy input.
